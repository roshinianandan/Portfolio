# Roshini A – Portfolio
React + TypeScript + Tailwind (Vite). Run locally: `npm install && npm run dev`. Build: `npm run build`.
Deploy: push to GitHub, import the repo at vercel.com/new (Vite preset is auto-detected), click Deploy.
Edit content at the top of `src/App.tsx`. Resume: `public/Roshini_A_Resume.pdf`. Photo: `public/roshini.jpg`.
